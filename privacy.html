Privacy Policy

ParsiLaTeX Code Save · Last updated: September 18, 2026

The ParsiLaTeX Code Save browser extension allows users to copy the contents of a code block to the clipboard by double-clicking on the code block on supported websites.

Data accessed

The extension accesses the contents of code blocks on supported web pages only when necessary to provide its copy-to-clipboard functionality.

Data collection and storage

ParsiLaTeX Code Save does not collect, transmit, upload, or remotely store user data. Code copied using the extension is processed locally within the user's browser and is placed only in the user's local clipboard.

The extension does not collect browsing history, personally identifiable information, authentication information, analytics data, or usage statistics.

Data sharing

No user data or website content is transmitted to the developer or shared with third parties.

External services

The extension does not communicate with external servers or third-party APIs.

Limited use

Any website content accessed by the extension is used solely to provide the extension's user-facing copy-to-clipboard functionality.

Changes

If the extension's data-handling practices change, this privacy policy will be updated accordingly.
